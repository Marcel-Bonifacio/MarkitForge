# Support

- **Bugs and feature requests:** open an issue on this repository. Please include
  the file type, the command or code you ran, and what you expected.
- **Security problems:** do not open a public issue; see [SECURITY.md](SECURITY.md).
- **Questions about upstream behaviour:** problems that also happen in
  [microsoft/markitdown](https://github.com/microsoft/markitdown) are best reported there too.

MarkitForge is a community project with no paid support or response-time guarantee.
