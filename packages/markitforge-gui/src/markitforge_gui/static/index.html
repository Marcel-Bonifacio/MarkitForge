AI options

Turns pages that are only a picture of text into text.

Adds a short description of each picture.

Math in PDFs becomes LaTeX you can edit.

Keeps the pictures as files. The .zip download puts them next to the .md file. Does not use AI.

AI provider

Kept in memory only while MarkitForge runs. Never saved to disk.
